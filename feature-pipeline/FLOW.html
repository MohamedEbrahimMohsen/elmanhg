Momenta Feature Flow

One GitHub story in, one merged PR per sub-task out. Agents do the work. The dev approves the split, the plan, and the PR. Nothing merges without a human.

PR = sub-task. Small task, small PR. Huge task, huge PR. Never cut by function. Next sub-task starts only after the previous one is merged.
