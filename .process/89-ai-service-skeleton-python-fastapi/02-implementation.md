## Notes for review
- **Local toolchain:** uv's first Python 3.13 download left a broken minor-version link (`cpython-3.13-windows-x86_64-none`), and `uv lock` failed with "Missing expected target directory". Removing that link fixed it. This affects the local machine only.
- **Auth and prompt-injection mutation checks were not run** (classifier denial). A reviewer or the dev may want to run them by hand: make `compare_digest` always true, expect P38/P39 to fail; make `strip_delimiters` return its input, expect P28 to fail.
- `core/problems.py` is 149 lines: under the python-feature 300-line cap, but above the .NET "~100 lines" guide (which is .NET-scoped).
- `field_errors_from`: a model-level validator error (for example the history alternation) has loc `("body",)`, so after the `body` prefix is dropped its `field` is `""`. That is as specified, but callers see an empty field name for body-level rules.
- The `.env.example` placeholder token `change-me-local-ai-service-token-0123456789` is 43 characters, so it passes both validators. The CI token `ci-only-service-token-not-a-secret-0123` is 39 characters.
- The `uvicorn.access` silencing means a local `--reload` run without `--no-access-log` also shows only `request.completed` lines. This is intentional under D14.
- `HttpAiServiceClientTests.ChatAsync_CallerCancelled_ThrowsOperationCanceled` asserts that the thrown `OperationCanceledException` is not wrapped. It uses a pre-cancelled token and the stub throws.
- The skill's delta bullet 1 says uv **0.12.17** (it follows the deviation above, not the plan's 0.12.18 text).
