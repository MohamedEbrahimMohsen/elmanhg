# Plan — Core.Settings: runtime settings and feature flags (E21.S9, story 312)

## Goal
The runtime-settings framework (typed keys, definitions, registry with startup validation, constraints, JSON values, value rules, the cached reader and the options) currently lives in `Elmanhg.Application/Shared/RuntimeSettings` and `Shared/Options`. After this story it lives in a new app-agnostic core project, `api/core-libraries/Core.Settings`. The project reads overrides through an override-store contract that the app implements. The app keeps its 22 concrete settings and feature flags, the `RuntimeSettingGroup` enum (group names and page order), the `RuntimeSettingOverride` entity and its `AppDbContext` mapping, and the Configuration endpoints, handlers and page. API, OpenAPI document, admin page, EF model and runtime behaviour stay byte-for-byte the same.

## Scope
**In:**
- New `Core.Settings` project (17 source files plus csproj), added to `Elmanhg.slnx` under `/core-libraries/`.
- App switch-over:
  - delete the 12 framework files and 2 options files from Application;
  - add `RuntimeSettingOverrideStore`;
  - the entity implements `IRuntimeSettingOverride`;
  - DI goes through `AddCoreRuntimeSettings`;
  - group strings come from `nameof(RuntimeSettingGroup.X)`;
  - every consumer swaps to `using Core.Settings;`.
- Tests: core coverage in `Elmanhg.Tests/Core/Settings/`; framework tests move there; app tests are updated for the new signatures, plus one new integration test for the store.
- Docs: `docs/constitution.md`, `.claude/skills/dotnet-feature/SKILL.md`, `docs/configuration.md`.

**Out:**
- `CoreDbContext` (unchanged; the entity mapping stays in `AppDbContext.RuntimeSettings.cs`).
- `Core.Notifications` (kept).
- Migrations: none, and `has-pending-model-changes` must stay clean.
- Error codes: no new ones; existing codes unchanged.
- Web: no change, and no client regeneration.
- `Elmanhg.slnx`, the constitution and SKILL.md get additive edits only.
- Everything in the parallel core-hygiene lane (dead code, package references, TimeProvider in core, audit actor stamping, ICurrentUser). No edit to any existing `Core.*` project.

**Deferred:** none.
