## Notes for review
- **Blue text vs logo.** Per the approval condition, `#0E64DA` (`accent-text`) is used for all blue text, and `#116EEE` stays for the logo, borders, rings, fills and icons. T8 guards the split. The S3 script also moved icon colours (`text-accent` on Lucide icons, such as the assistant sparkle) to `accent-text`. That is a slightly darker blue on icons, and it was intentional (the class only sets `color`).
- **Mint count.** After the fixes, the `primary` check finds at most one mint button on every audited page. Pages where the main action is not mint (blueprints, per-card subscribe) now have none. The blueprint editor's Save and Cancel are both outline buttons; making Cancel `ghost` would restore the hierarchy, but the plan did not ask for it.
- **Lane files** (#286 option cards, #288 assistant page and chat) were restyled only through the scripts and tokens, as planned.
- **Pre-existing, not fixed:** the `/admin/payments` student-name button is 78×21 (D3), and the English student nav overflows at 900 px, so headless Chrome shows a scrollbar (D4). The old build has both.
- **Arabic on admin English pages.** The `/admin` English pages still load Almarai, because the demo's seed content (subject and student names) is Arabic.
- **Line endings.** The worktree checks out CRLF (`core.autocrlf=true`). Edited files were kept CRLF. New files are LF; git normalises them on add.
- **Driver.** The audit driver, logins and scratch builds stay in the session scratchpad. No credentials are in any committed file.
