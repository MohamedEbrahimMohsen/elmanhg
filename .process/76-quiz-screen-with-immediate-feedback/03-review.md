# Review — Quiz screen with immediate feedback (#76, E5.S3), round 1

## Blocking

### 1. The finish-error path of `useFinishQuiz` has no test
**Where:** `web/src/features/quiz/hooks/useFinishQuiz.ts:23-27` (coverage: 0% branches, lines 24-26 uncovered, re-run by the reviewer)
**Rule:** `.claude/conventions/react-testing.md` "What to test at which level" (a feature mutation hook must cover success, error mapping, and the invalidation effect visible in the UI) and "Coverage" (every branch on new lines has a test); plan Definition of done: "Answer and finish errors toast the localised code and invalidate the session query".
**Problem:** `onError` (toast by `ApiError.code` and `invalidateQueries`) is never run by any test. The implementer says so under "Notes for review", but the plan's DoD claims this behaviour, and nothing checks it. The answer hook's matching branch is tested (QuizPage test "reloads the session when the answer conflicts"). The finish hook's branch is not.
**Failure:** "End practice" gets a 409 `SESSION_MODIFIED_CONCURRENTLY` (a concurrent answer), or a 400 `SESSION_ALREADY_SUBMITTED` (finished in another tab). The student should see the localised toast, and the session should reload: the quiz, or a redirect to the result via `QuizPage.tsx:29-31`. If you delete `onError`, drop the `invalidateQueries`, or use the wrong i18n key, all 488 tests still pass.
**Fix:** Add one QuizPage test. The finish handler calls `server.use(getGetSessionMockHandler(finished(...)))` and returns `HttpResponse.json({ code: 'SESSION_ALREADY_SUBMITTED' }, { status: 400 })`. Assert the toast text "This session has already ended." and then the heading "Practice result", which the invalidation plus the Decision 12 redirect produce. Use the same pattern as test #60.
