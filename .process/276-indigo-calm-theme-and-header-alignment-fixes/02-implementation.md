## Budget cleanup (quiz 261 158 → 260 581 B brotli, limit 261 120)
Found with a per-chunk brotli breakdown of the `perf:budget` quiz entries (same manifest walk and brotli settings), diffed against a build of base. The limit was not raised and the logo target-size fix is kept.
1. **Lazy chunk no longer forces a router-helper split** (`TopNavMore.tsx`, `TopTabs.tsx` unchanged): see Deviations. This removed the extra `useMatch-*.js` and `redirect-*.js` chunks from every page, about −290 B.
2. **No `cn`/`tailwind-merge` dependency in the lazy chunk**: the More button class is a template string. The two parts never conflict, so twMerge was dead work. This drops `utils-*.js` from the `__vite__mapDeps` preload list in the shell chunk.
3. **Shared CSS rules**: `pillTabClassName` uses `data-[status=active]:*` (Deviations), which removes two duplicate rules.
4. **Dead CSS**: `app.css` now has `@source not '../../scripts';` and `@source not '../**/*.test.{ts,tsx}';`. Tailwind had been generating utilities from string literals in the token contrast test (`.accent-soft`, `.text-muted`). Index CSS went from 56 852 to 56 095 B raw.
5. **Duplicate class string**: `button.tsx` primary and accent share one `accentFillClassName` constant (D5 says they are identical).
Note: about ±100–200 B of the brotli total is hash churn (the entry chunk holds 183 hashed file names). That is why I aimed for a wide margin rather than the 38 B gap.
