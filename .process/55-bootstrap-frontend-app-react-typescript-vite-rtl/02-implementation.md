## Notes for review
- **Deviation 2 is a real trade-off.** Tests no longer exercise React Compiler output. The alternative was failing the plan's coverage threshold for reasons unrelated to test quality. If the reviewer prefers the compiler on in tests, the threshold (or coverage over compiled code) has to change in the plan.
- **i18n JSON is nested** (`{"errors": {"UNHANDLED_EXCEPTION": …}}`), because i18next's default `keySeparator` is `.`.
- **`TopTabs`/`TabBar`** declare `TopTabsProps`/`TabBarProps { role: Role }`. The plan gave the markup only; the skill requires an `XProps` type.
- **`TabBar`** builds its item list as `tabBarItems(nav)` plus a synthetic `{ key: 'more', to: morePath, labelKey: 'nav.more', icon: Ellipsis }` when `morePath` is set, so one `Link` template renders both.
- **Prettier's Tailwind plugin reordered class lists** in several components (for example, `focus-visible:outline-hidden` now sorts after `ring-*`). The class sets match the contracts.
- **`app.css` uses single-quoted `@import`s and font names**, because Prettier applies `singleQuote` to CSS. The meaning is identical to the plan's double quotes.
- **`tsconfig.node.json`** carries `verbatimModuleSyntax`, `moduleDetection force` and `noEmit`, on top of the listed flags. `noEmit` is required for `allowImportingTsExtensions`.
- **`http.ts` imports `@/app/env`.** Contract F4 requires `env.VITE_API_BASE_URL`, so `shared/lib` depends on `app/env`, which in turn imports `roles` from `@/features/session`. There is no cycle at runtime (verified by build and tests), but it is a shared → app → feature edge.
- **Nothing was committed or staged.** The real git index is untouched. `web/package-lock.json` is in the tree to commit; `node_modules`, `dist` and `coverage` are ignored by the root `.gitignore`.
- **Browser-mode visual tests stay deferred** per the plan's Deferred section. The orchestrator should open the issue.
