# Plan — [E12.S2] JSONL export (+ #229 essay-grade training records)

## Goal
An admin opens `/admin/export`, picks a source (Ask a Teacher, Avatar, Attempts, Essay grades), a date range and an optional subject, and requests an export. A background job streams the matching training records in keyset pages into a JSONL file. The job strips PII from every free-text field, replaces source ids with keyed pseudonyms, and stores the file under a private `training-exports/` folder through `IFileStorage`. The admin then gets a short-lived signed link and downloads the file. The export request and every link issuance are audited. As part of #229, a completed AI essay grade now writes an append-only `EssayGradeTrainingRecord`, so AI grading data (PRD §13 "AI grading (v2)") reaches the training tables and can be exported.

## Scope
**In:** `TrainingExport` aggregate + worker (request → run → complete/fail with retry). A signed capability download link, anonymous file endpoint and admin list. Private storage folder. A PII scrubber and id pseudonymisation. `EssayGradeCompleted` domain event → `EssayGradeTrainingRecords` (append-only). Admin export page (form + list + download). Audit rows. Docs, OpenAPI, Orval, Postman.
**Out:** name stripping from free text (see D11). Teacher override training rows (E17/#128, because no resolve path exists: `EssayGrade` has no accept/override method today). Cleanup of orphaned/old export files. Retention (#215).
**Deferred:** none. Storage uses the existing `IFileStorage` (Local + S3 adapters already built), so nothing needs credentials.

## Decisions
| # | Question | Decision | Why |
|---|----------|----------|-----|
| D1 | Streamed HTTP response vs background job + storage? | **Background job + storage.** `POST` creates a `Pending` `TrainingExport`. `TrainingExportWorker` (BackgroundService, scope per item, mirrors `EssayGradingWorker`) runs it. The file goes to `IFileStorage`, and the admin downloads it through a signed link. | Story sub-task says "export job producing files to object storage with signed download links". No request thread is held while rows are read. Retries and a status list come free. The download itself is an async stream copy. |
| D2 | Memory bound while reading | Keyset paging on `(OccurredAt, Id)` using the Npgsql row-value comparison `EF.Functions.GreaterThan(ValueTuple.Create(x.OccurredAt, x.Id), ValueTuple.Create(after.OccurredAt, after.Id))`, `AsNoTracking`, page size `TrainingExports:ReadBatchSize` (500). Lines are written to a temp file (`FileOptions.DeleteOnClose`), then the stream is handed to `IFileStorage.SaveAsync`. | `EnableRetryOnFailure` makes EF buffer whole result sets, so `AsAsyncEnumerable` would not really stream. Pages keep at most one batch in memory, and each page can be retried. The awaited repository call in the loop is paging, not N+1. S3 `PutObject` needs a seekable stream, so the data goes through a temp file. |
| D3 | Where AI essay grades go (#229) | New append-only table `EssayGradeTrainingRecords`, written by `EssayGradeTrainingRecordHandler` on a new `EssayGradeCompleted` event raised in `EssayGrade.Complete` (both `Graded` and `InReview/LowConfidence`). It is **not** `AttemptTrainingRecords`. | No `Attempt` exists when the AI grade completes: #119 writes the Attempt later. `AttemptTrainingRecords.AttemptId` is unique and non-null, and faking it with the grade id would create a duplicate row once #119's Attempt fires `AttemptsRecorded`. `AttemptTrainingRecord` has no columns for criteria, confidence, justification, model or prompt version. PRD §13 lists "AI grading" as its own source, and exports are "per source". The final essay Attempt still reaches `AttemptTrainingRecords` through the existing `AttemptsRecorded` handler once #119 writes it. **Deviation from the orchestrator's literal wording, flagged.** |
| D4 | Teacher resolve event | Not added. No resolve/override method exists on `EssayGrade`. #128/E17 adds that event and a `Trigger` column. | Nothing to hook. |
| D5 | Signed link mechanism | `POST /api/training-exports/{id}/download-link` (admin, audited) creates a 32-byte `RandomNumberGenerator` token (base64url) and stores its SHA-256 hex plus expiry (`DownloadLinkLifetimeMinutes`, default 10) on the export. It returns `/api/training-exports/{id}/file?token=…`. The anonymous `GET …/file` checks the hash with `CryptographicOperations.FixedTimeEquals` and the expiry, then streams from `IFileStorage.OpenReadAsync`. A new link replaces the old one. | Provider-agnostic (Local and S3). Needs no new secret and no `IFileStorage` change. Can be revoked. Works across replicas because the state lives in the DB. The SPA uses Bearer tokens, so a browser navigation cannot authenticate; a capability URL is the same pattern as an S3 presigned URL. `CoreRequestLoggingMiddleware` already redacts query values. |
| D6 | `[AllowAnonymous]` on the file endpoint | Allowed, as a documented exception to "AllowAnonymous only for public reads". The 256-bit, 10-minute token is the authorisation. Only an admin (policy `TrainingData.Export`) can mint one, and minting is audited. Any failure → 404 `TRAINING_EXPORT_NOT_FOUND`, so existence is not leaked. | Same justification as Paymob webhooks (non-JWT auth). |
| D7 | Keep the files private | New constant `TrainingExportFiles.StorageFolder = "training-exports"`, added to both private-folder checks (`PublicMediaMiddleware.IsPublicKey` for S3 and the `PublicMediaFileProvider` list for Local). The key is `training-exports/{exportId:N}-{random:N}.jsonl`. | Without this, `/api/media/training-exports/...` would be served publicly. A random suffix per run avoids the Local `CreateNew` clash on retry. |
| D8 | PII stripping | `TrainingDataScrubber` (Application). Every string value in every exported free-text field **and** inside every exported JSON column (answer, grade, context, messages, criteria) is scrubbed, in this order: email → `[email]`, URL (`https?://…` or `www.…`) → `[url]`, `@handle` (≥3 word chars, applied after emails) → `[handle]`, any run of ≥8 digits (ASCII, Arabic-Indic U+0660–0669, Persian U+06F0–06F9, optional single `+` prefix, optional single space/`-`/`.` between digits) → `[number]`. That covers Egyptian mobiles, +20 numbers and 14-digit national ids. All regexes use `RegexOptions.NonBacktracking \| CultureInvariant` (email/url also `IgnoreCase`). | Contact identifiers are the realistic PII in student text. Linear time. A numeric answer of 8+ digits is also masked, which is accepted and documented. |
| D9 | Raw ids (`docs/training-data.md` open item) | Never exported: `AttemptId`, `ConversationId`, message ids, `ThreadId`, `EssayGradeId`, and JSON keys (any depth, case-insensitive) `attemptId, sessionId, conversationId, threadId, studentId, userId, teacherId, messageId, studentMessageId, assistantMessageId, essayGradeId` are removed. Each line carries `recordId` (the training row's own random id, which is in no operational table). Grouping keys are `conversationKey` = `IStudentIdHasher.HashSourceId("avatar-conversation", id)` and `threadKey` = `HashSourceId("teacher-thread", id)` (HMAC with the same server key, domain-separated by scope). Content ids (subject/unit/lesson/question) are kept. | Content ids are not personal. A pseudonym per scope lets consumers rebuild conversations and dedupe threads without linking back. |
| D10 | Teacher threads: which snapshot | For each thread, the latest snapshot **inside the range** only (NOT EXISTS a later in-range row; at equal `OccurredAt`, `RatedAfterClose` beats `Closed`). | `docs/training-data.md` says "#110 takes the latest snapshot per thread". |
| D11 | Names in free text | Not stripped. This residual risk is documented in `docs/training-data.md`, and the page copy says contact data is removed from texts rather than claiming names are. | No reliable detector exists: a display-name dictionary gives false positives on common Arabic words. This is a human/legal follow-up alongside #215. |
| D12 | Filters | `source` (required), `[from, to)` UTC (`from < to`, span ≤ `MaxRangeDays` 366), optional `subjectId` (unknown → 404 `SUBJECT_NOT_FOUND` via the existing `DashboardSubjectGuard`). The range is on `OccurredAt`. | Matches the doc ("#110 exports by date range on OccurredAt") and the dashboard's subject filter. |
| D13 | Concurrent runs across replicas | `TrainingExport.Version` is `xmin`. The loser's save throws; `AppDbContext` maps this to 409 `TRAINING_EXPORT_MODIFIED_CONCURRENTLY`. The worker then sends `FailTrainingExportCommand`, which is a no-op on a Completed export. The loser's uploaded file is orphaned (documented). | Same pattern as `EssayGrade`. |
| D14 | Audit | `RequestTrainingExportCommand` (`TrainingExport.Request`, id from result) and `CreateTrainingExportDownloadLinkCommand` (`TrainingExport.CreateDownloadLink`) implement `IAuditableCommand`. `TrainingExport` implements `IAuditedEntity`, so the diff shows source, range and subject. `DownloadTokenHash` carries `AuditChangeReader.ExcludedAnnotation`. Worker commands and the anonymous download are not audited. | This is the "Export audit entry" sub-task. The token hash never reaches the widely readable diff. |
| D15 | JSON dialect of lines | `TrainingExportJson.SerializerOptions`: `JsonSerializerDefaults.Web`, `JsonStringEnumConverter()` (PascalCase names like the API), nulls written, `Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping` (WHY comment: the file is served as an `application/x-ndjson` attachment with nosniff, never HTML, and Arabic stays readable). One object per line, `\n` terminated, UTF-8 without BOM. | §8.6: states its options explicitly. |
| D16 | Web download trigger | "تنزيل" → mutation → `startDownload(resolveApiUrl(url))` creates a temporary `<a href download rel="noopener">`, clicks it and removes it. | Same approach as the prototype. There is no blob in memory. |
| D17 | Live status | The list query polls every 5000 ms while any row is `Pending` (`refetchInterval`). | No push channel needed for an admin tool. |

## Domain behaviour
```csharp
// TrainingExport.cs
public static TrainingExport Request(TrainingExportSource source, DateTimeOffset from, DateTimeOffset to, Guid? subjectId, Guid requestedBy, DateTimeOffset requestedAt)
{
    if (from >= to) { throw new ArgumentException("An export range must end after it starts.", nameof(to)); }
    var at = ToMicroseconds(requestedAt);
    return new TrainingExport(Guid.NewGuid(), requestedBy) { Source = source, From = ToMicroseconds(from), To = ToMicroseconds(to), SubjectId = subjectId, Status = TrainingExportStatus.Pending, Attempts = 0, NextAttemptAt = at, RequestedAt = at };
}
public bool IsDueAt(DateTimeOffset now) => Status == TrainingExportStatus.Pending && NextAttemptAt <= now;

// TrainingExport.Lifecycle.cs
public void Complete(string fileKey, long rowCount, long fileSizeBytes, string sha256, DateTimeOffset completedAt)
{ EnsurePending(); var at = ToMicroseconds(completedAt); Attempts++; FileKey = fileKey; RowCount = rowCount; FileSizeBytes = fileSizeBytes; Sha256 = sha256; NextAttemptAt = null; LastErrorCode = null; CompletedAt = at; Status = TrainingExportStatus.Completed; UpdationDate = at; }

public void FailAttempt(string errorCode, DateTimeOffset failedAt, int maxAttempts, TimeSpan retryBaseDelay)
{ EnsurePending(); var at = ToMicroseconds(failedAt); Attempts++; LastErrorCode = errorCode.Length <= ErrorCodeMaxLength ? errorCode : errorCode[..ErrorCodeMaxLength];
  if (Attempts >= maxAttempts) { Status = TrainingExportStatus.Failed; NextAttemptAt = null; } else { NextAttemptAt = at + (retryBaseDelay * Math.Pow(2, Attempts - 1)); }
  UpdationDate = at; }

public void IssueDownloadLink(string tokenHash, DateTimeOffset expiresAt, DateTimeOffset issuedAt)
{ if (Status != TrainingExportStatus.Completed) { throw new ConflictCoreException(ErrorCodes.TrainingExportNotReady); }
  DownloadTokenHash = tokenHash; DownloadLinkExpiresAt = ToMicroseconds(expiresAt); UpdationDate = ToMicroseconds(issuedAt); }

public bool AcceptsDownloadToken(string tokenHash, DateTimeOffset now) =>
    Status == TrainingExportStatus.Completed && DownloadTokenHash is { } stored && DownloadLinkExpiresAt > now
    && CryptographicOperations.FixedTimeEquals(Encoding.UTF8.GetBytes(stored), Encoding.UTF8.GetBytes(tokenHash));

private void EnsurePending() { if (Status != TrainingExportStatus.Pending) { throw new ConflictCoreException(ErrorCodes.TrainingExportNotPending); } }
```
`EssayGradeTrainingRecord.From`: `ArgumentException.ThrowIfNullOrWhiteSpace(studentHash)`. `placement.QuestionId != grade.QuestionId` → `InvalidOperationException("Placement does not belong to the grade's question.")`. `grade.Status == Pending` or any of `GradedAt/Score/NormalisedScore/Criteria/Justification/Confidence/Model/PromptVersion` null → `InvalidOperationException("Only a completed AI grade becomes a training record.")`. Copies: `EssayGradeId = grade.Id`, question/version, placement ids, `SessionKind = sessionKind`, `Answer = grade.Answer`, `MaxScore`, score fields, `Criteria`, `Justification`, `Confidence`, `Outcome = grade.Status`, `Model`, `PromptVersion`, `OccurredAt = grade.GradedAt`, `RecordedAt = recordedAt`. No mutating methods.

`EssayGrade.Complete`: unchanged state logic, plus `RaiseDomainEvent(new EssayGradeCompleted(this));`. `FailAttempt` raises nothing.

## Definition of done
- [ ] `EssayGrade.Complete` raises `EssayGradeCompleted`; a completed AI grade in a non-test session writes exactly one `EssayGradeTrainingRecords` row in the same save; test mode writes none.
- [ ] `EssayGradeTrainingRecords` has no FKs, has a unique `EssayGradeId`, and rejects UPDATE/DELETE/TRUNCATE by trigger.
- [ ] `POST /api/training-exports` is admin-only (`TrainingData.Export`), validates source/range/subject, and writes an audit row `TrainingExport.Request`.
- [ ] Worker `TrainingExportWorker` uses a scope per item, has a kill switch `TrainingExports:SweepEnabled` (off in ApiFactory), retries with backoff, and ends Failed after `MaxAttempts`.
- [ ] The export reads in keyset pages of `ReadBatchSize` with `AsNoTracking`; nothing materialises the full range.
- [ ] The file goes to `training-exports/…` via `IFileStorage`; that folder is not served by either public media path (Local and S3).
- [ ] The download link is admin-only, audited (`TrainingExport.CreateDownloadLink`), uses a 256-bit token stored as SHA-256 only, expires after `DownloadLinkLifetimeMinutes`, and is compared in fixed time; every failure → 404 `TRAINING_EXPORT_NOT_FOUND`.
- [ ] `DownloadTokenHash` is excluded from the audit diff.
- [ ] Exported lines contain no student id, no HMAC key, no raw source ids (D9), and scrubbed free text (D8); threads export only the latest in-range snapshot.
