# React feature handbook

Stack: **React 18 · TypeScript strict · Vite · TanStack Query · React Hook Form + Zod · Tailwind + shadcn/ui · i18next (AR/EN, RTL)**
  → 2026-09 update: Stack is **React 19.2 + React Compiler 1.0 · TypeScript strict (typecheck with TS 6.0; TS 7 native `tsc` allowed for CI speed only, typescript-eslint not yet on TS 7) · Vite 8 (Rolldown, Node ≥ 22.12) · TanStack Query v5 (+ TanStack Router v1 for new apps) · React Hook Form + Zod 4 (`@hookform/resolvers` v5) · Tailwind CSS v4 (CSS-first `@theme`, no `tailwind.config.*`) + shadcn CLI v4 · Orval 8 · i18next (AR/EN, RTL)**. React 18 idioms are findings (§23).
Design: every visual value comes from `.claude/design-system.md` (the Glass system, mirrored from `docs/design-system.md`). There is no Figma. Every screen's content, flow and states come from the working prototype in `prototype/` (open the matching route in `prototype/app.js`) and `docs/claude-design-prompt.md` §4–§6; the look comes only from the design system.

## 1. Layout

- One feature = one folder `src/features/<feature>/` with `api/`, `components/`, `hooks/`, `pages/`, `schemas/`, `index.ts`.
- Pages under `pages/`, routed in `src/app/router.tsx`. Shared UI only in `src/components/ui/` (shadcn) and `src/components/shared/`.
- No file over 200 lines. A component over 120 lines gets split.
- Barrel export per feature (`index.ts`). Nothing imports across features except through the barrel.
- Orval output lives in `src/shared/api/generated/` (or the repo's existing generated folder). Never hand-edit it; CI regenerates and runs `git diff --exit-code`.
- Design tokens CSS lives in one generated file (`src/styles/tokens.css`), imported by the Tailwind entry CSS. Never hand-edit it.
- Route files (TanStack file routes or `router.tsx` entries) hold no business logic: loader + component import only.
- Tests live next to the code they test (`X.test.tsx` beside `X.tsx`, or `__tests__/` inside the feature). E2E specs in `e2e/`.

## 2. Naming

- Components `PascalCase.tsx`, one component per file, named export. Hooks `useX.ts`. Schemas `xSchema.ts`. API hooks `useGetX`, `useCreateX` (generated by Orval; never hand-written fetch).
- Props type `XProps`, colocated. No `I` prefix, no `any`, no `as unknown as`.
- Translation keys `feature.screen.element` in `locales/ar.json` and `locales/en.json`, both always.

## 3. Forbidden

- `useEffect` for data fetching. Data comes through TanStack Query hooks only.
- `useState` for server data. Local state is UI state only.
- Inline styles, arbitrary Tailwind values (`w-[137px]`), raw hex colours, raw font sizes. Tokens only.
- `console.log` in committed code. `// TODO`. Commented-out code.
- Default exports (except route lazy pages). `React.FC`.
- `any`, non-null assertions `!`, `@ts-ignore`.
- Hard-coded strings visible to users. Everything through `t()`.
- Fetching, mutation, or navigation inside a shared `ui/` component.
- `forwardRef` in new code (React 19: `ref` is a prop). `<Context.Provider>` in new code (render `<Context value>`). `defaultProps`/`propTypes` on function components.
- `useMemo`/`useCallback`/`React.memo` added without a `// perf:` comment citing profiler evidence (React Compiler memoizes).
- Direct `fetch`/axios calls in a feature. All HTTP goes through the Orval mutator (`http`).
- `dangerouslySetInnerHTML` anywhere except the one `SafeHtml` component that runs `DOMPurify.sanitize()`.
- Tokens in `localStorage`/`sessionStorage`. Secrets in `VITE_*` variables (everything `VITE_*` ships to the browser).
- `tailwind.config.js`/`.ts`, `@tailwind base;` directives, `tailwindcss-animate` (Tailwind v3 setup).
- Array index as `key` for dynamic lists. `div`/`span` with `onClick` for actions.

## 4. Required

- Every form: `react-hook-form` + `zodResolver` with a schema in `schemas/`. Zod messages are translation keys.
- Every list/detail page: loading, empty, error states, all three, matching the prototype screen for each.
- Every mutation: optimistic update or query invalidation declared in the hook, toast on success and error via the shared toast.
- RTL-safe: logical properties (`ms-`, `me-`, `start`, `end`), never `ml-`/`mr-`/`left`/`right`.
- Accessible: labelled inputs, `aria-*` on custom controls, keyboard reachable, focus visible.
- Tenant/host context read from the shared provider, never from `window.location` in a feature.
- Every query fetcher receives the `signal` (Orval `override.query.signal: true`) so navigation cancels in-flight requests.
- Every server validation error (`ApiError.fieldErrors`) is mapped to `form.setError(field, …)`; focus moves to the first invalid field.
- Language switch sets `document.documentElement.lang` and `dir = i18n.dir(lng)`.
- Focus ring via token (`focus-visible:ring-2 ring-ring ring-offset-2`); never `outline-hidden` without a `focus-visible` replacement.
- Interactive targets ≥ 24×24 CSS px (WCAG 2.5.8); primary actions ≥ 44×44 (`min-h-11 min-w-11`).
- Filters, sort, pagination live in the URL search params, validated with Zod.

## 5. Tests

- Vitest + Testing Library. One test file per component/hook with logic: `X.test.tsx`.
- Test behaviour through the DOM (`getByRole`, `getByLabelText`), never implementation details.
- Every form schema has a test per rule (valid, and each failing case).
- MSW for API hooks; no mocking of TanStack Query itself.
- Full rules: `.claude/conventions/react-testing.md`. It wins on test detail.
- Every data screen has tests for loading → success, empty, error + retry, and one `ar` (RTL) render.
- Never edit, skip (`it.skip`, `test.skip`, `xit`, `.only`), or delete an existing test to make it pass. A wrong test → `BLOCKED: <test> — <why>` in the report.

`vite.config.ts` (Vite 8 + `@vitejs/plugin-react` v6; the old `react({ babel: {...} })` form does not work):

```ts
import { defineConfig } from 'vite';
import react, { reactCompilerPreset } from '@vitejs/plugin-react';
import { babel } from '@rolldown/plugin-babel';
import tailwindcss from '@tailwindcss/vite';
import { tanstackRouter } from '@tanstack/router-plugin/vite';

export default defineConfig({
  plugins: [
    tanstackRouter({ target: 'react', autoCodeSplitting: true }), // before react()

```

Exact exports of `@vitejs/plugin-react` / `@rolldown/plugin-babel` change fast — verify with `npm view @vitejs/plugin-react version` and the package README before copying.

## 8. State & data fetching

- Server state = TanStack Query only. UI state = `useState`/`useReducer`. Cross-tree UI state = context or a small Zustand store. Never copy query data into state.
- One `queryOptions()` factory per query; key shape `[feature, scope, params]`:
```ts
export const invoiceKeys = {
  all: ['invoices'] as const,
  list: (f: Filters) => [...invoiceKeys.all, 'list', f] as const,
  detail: (id: string) => [...invoiceKeys.all, 'detail', id] as const,
};
export const invoiceQuery = (id: string) =>
  queryOptions({ queryKey: invoiceKeys.detail(id), queryFn: ({ signal }) => getInvoice(id, { signal }) });
```
- `QueryClient` defaults: `staleTime: 30_000`, `retry: 1`. Mutations invalidate by key prefix in `onSuccess`, or optimistic via `onMutate` + rollback in `onError`.
- v5 names only: `isPending`, `gcTime`, `placeholderData: keepPreviousData`, `throwOnError`, object-form `useQuery({ queryKey, queryFn })`.
- Route loaders prefetch with `context.queryClient.ensureQueryData(q)`; components read with `useSuspenseQuery(q)`.
- React 19.2: `useEffectEvent` for effect callbacks that need latest props; `<Activity mode="hidden">` to keep hidden tab state; `useOptimistic` only for local-only optimistic UI.
- Logout calls `queryClient.clear()`.

## 9. Forms & validation

```ts
const schema = z.object({
  email: z.email({ error: 'validation.email' }),   // Zod 4: top-level formats, `error` param
  amount: z.coerce.number().positive(),
  dueDate: z.iso.date(),
});
type FormValues = z.infer<typeof schema>;
const form = useForm<FormValues>({ resolver: zodResolver(schema), defaultValues, mode: 'onBlur' });
```
- shadcn `Form`/`Field`: every input has a label, `aria-describedby` to helper/error, `aria-invalid` when invalid.
- Submit disabled only while `isSubmitting`. Never disabled for "form invalid".
- RHF `handleSubmit` owns submit. Do not mix `useActionState` into an RHF form.
- Zod 4 API: `z.record(k, v)` (2 args), `z.strictObject`, `z.treeifyError`, `z.enum` (no `nativeEnum`).
- Generated Zod schemas (Orval `client: 'zod'`) validate API shapes; form schemas live in `schemas/` and may extend them.

## 10. Routing

- Existing app: keep its current router; do not migrate in a feature PR.
- New app: TanStack Router v1, file-based, typed. `declare module '@tanstack/react-router' { interface Register { router: typeof router } }`.
- Router defaults: `defaultPreload: 'intent'`, `defaultPreloadStaleTime: 0` (Query owns caching), `defaultErrorComponent`, `defaultNotFoundComponent`.
- Auth guard only in the layout route `_app.tsx` `beforeLoad` → `throw redirect({ to: '/login', search: { redirect: location.href } })`.
- Search params validated with Zod (`validateSearch`). No React Router v6 idioms (`<Routes>`, `useNavigate` from `react-router`) in a TanStack Router app.

## 11. API client generation (Orval 8)

```js
// orval.config.mjs — Orval 8 is ESM-only, Node >= 22.18, fetch is the default client
import { defineConfig } from 'orval';
export default defineConfig({
  api: {
    input: { target: '../contracts/openapi.yaml' },
    output: {
      mode: 'tags-split', target: 'src/shared/api/generated', schemas: 'src/shared/api/generated/model',
      client: 'react-query', httpClient: 'fetch',
      override: { mutator: { path: 'src/shared/lib/http.ts', name: 'http' },
                  query: { useQuery: true, useSuspenseQuery: true, signal: true } },
      mock: { generators: [{ type: 'msw' }] },
    },
  },
  apiZod: { input: '../contracts/openapi.yaml',
            output: { client: 'zod', mode: 'tags-split', target: 'src/shared/api/generated/zod' } },
});
```
- `npm run gen:api` = `orval`. CI: `npm run gen:api && git diff --exit-code src/shared/api/generated`.
- Mutator `http.ts`: base URL from validated env, `credentials: 'include'`, CSRF header on non-GET, maps non-2xx ProblemDetails to typed `ApiError { status, code, message, fieldErrors }`.
- Endpoint missing from the spec → backend adds it to OpenAPI first. Never hand-write a fetcher for it.

## 12. Loading / error / empty states

| State | Rule |
|---|---|
| Loading | Skeleton matching final layout (no layout shift). Route `pendingComponent` + Suspense. `aria-busy="true"` on the region. |
| Error | Route `errorComponent` + `QueryErrorResetBoundary`; message from i18n by `ApiError.code`; "Retry" calls `reset()`. Never raw JSON/stack. |
| Empty | Empty state with primary CTA, as in the prototype. "No data" and "no results for filter" are different states; the latter offers "Clear filters". |
| Mutation result | Toast (`role="status"`) for transient outcomes; blocking form errors inline. |

## 13. Auth token handling

- Default: backend/BFF sets `HttpOnly; Secure; SameSite=Lax|Strict` cookies. The SPA never reads a token. CSRF header on state-changing requests.
- Bearer unavoidable: access token in a module variable (memory only), refresh token in HttpOnly cookie, single-flight refresh on 401, retry once, then redirect to login.
- Never `localStorage`/`sessionStorage`/`document.cookie` for tokens.

## 14. i18n + RTL (Arabic)

- i18next namespace per feature; code uses keys only. `i18next-icu` for Arabic plurals (zero/one/two/few/many/other).
- On language change: `document.documentElement.lang = lng; document.documentElement.dir = i18n.dir(lng);`.
- Logical utilities only: `ms-/me-/ps-/pe-`, `start-/end-`, `text-start/end`, `border-s/e`, `rounded-s/e`. CI grep fails on `\b(ml|mr|pl|pr|left|right)-[0-9]|text-(left|right)\b` in `src/features`.
- Mirror directional icons (`rtl:rotate-180` on chevrons/arrows). Never mirror logos, media controls, checkmarks.
- Numbers/dates via `Intl.NumberFormat`/`Intl.DateTimeFormat(locale)`; digit system (`ar-EG` vs `ar-EG-u-nu-latn`) as the product decides in design-system.md.
- shadcn RTL support + `DirectionProvider` so portals (dialogs, popovers) get `dir`.

## 15. Accessibility (WCAG 2.2 AA)

- Semantic HTML: `<button>` actions, `<a href>` navigation, landmarks `<header> <nav> <main>`, one `<h1>` per page, no skipped heading levels.
- Focus visible (2.4.7) and not obscured by sticky headers (2.4.11): `scroll-padding-top` = header height token.
- Target size ≥ 24×24 (2.5.8); every drag has a click/keyboard alternative (2.5.7).
- Auth forms allow paste and password managers: `autocomplete="current-password"`, `one-time-code` (3.3.8). No re-asking data already given in the flow (3.3.7). Help link in the same place on every page (3.2.6).
- Contrast 4.5:1 text, 3:1 large text and UI components — verified once on tokens in design-system.md.
- Dialogs only from shadcn/Base UI primitives (focus trap, `Esc`, focus return). Icon-only buttons have an i18n `aria-label`. Async results in `aria-live="polite"`.
- `motion-safe:` / `prefers-reduced-motion` respected for every animation.
- Enforced by: `eslint-plugin-jsx-a11y` strict, `vitest-axe`/`jest-axe` in component tests, `@axe-core/playwright` in E2E.

## 16. Theming from design tokens

- Tailwind v4 CSS-first. Entry CSS:
```css
@import "tailwindcss";
@import "tw-animate-css";
@import "./tokens.css";                 /* generated: --ds-* variables, .dark overrides */
@custom-variant dark (&:where(.dark, .dark *));
@theme inline {
  --color-background: var(--ds-color-bg);
  --color-foreground: var(--ds-color-fg);
  --color-primary: var(--ds-color-primary);
  --radius-md: var(--ds-radius-md);
}
```
- Feature code uses semantic utilities only (`bg-primary text-foreground rounded-md p-4`). CI grep fails on `#[0-9a-fA-F]{3,8}`, `\[[0-9.]+(px|rem)\]`, `\b(bg|text|border|ring)-(slate|gray|zinc|neutral|red|orange|amber|yellow|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|pink|rose)-[0-9]{2,3}\b` in `src/features`.
- Missing token → UI/UX team adds it to design-system.md → regenerate tokens.css. Never inline a literal.

## 17. Responsive

- Mobile-first. Breakpoints are tokens (`--breakpoint-*` in `@theme`).
- Verified at 390 and 1280 wide (sanity 768). No horizontal scroll at 320 (WCAG 1.4.10).
- Components reused at different widths use container queries (`@container`, `@md:`).
- Tables become a card list under `md`.

## 18. Performance

- React Compiler on; manual memo only as an escape hatch with a `// perf:` comment.
- Route-level code splitting (`autoCodeSplitting`); `lazy()` for heavy widgets (charts, editors).
- Lists > 100 rows virtualized with `@tanstack/react-virtual`.
- Images: explicit `width`/`height`, `loading="lazy"` below the fold, `fetchpriority="high"` on the LCP image.
- Budget on mid-tier mobile: LCP < 2.5 s, INP < 200 ms, CLS < 0.1.

## 19. Security

- Raw HTML only through `SafeHtml` (DOMPurify). ESLint `react/no-danger` = error elsewhere.
- User-supplied URLs: `new URL()` + protocol allow-list (`https:`, `mailto:`). No `javascript:`/`data:` in `href`/`src`.
- `postMessage` listeners check `event.origin`. Third-party scripts pinned with SRI.
- Env validated with Zod at boot (`app/env.ts`); everything `VITE_*` is public.
- RSC in use (Next.js, React Router RSC, Vite RSC) → `react-server-dom-*` ≥ 19.0.1 / 19.1.2 / 19.2.1 (CVE-2025-55182). Server actions validate authn, authz, input.
- CSP from hosting without `unsafe-inline` scripts. `npm ci` with committed lockfile.

## 23. LLM mistakes to avoid

| Mistake | Correct |
|---|---|
| React 18 patterns: `forwardRef`, `<Ctx.Provider>`, `ReactDOM.render`, `defaultProps`, `propTypes`, string refs | React 19: `ref` prop, `<Ctx value>`, `createRoot` |
| `useEffect(() => { fetch().then(setData) }, [])` | Query hook / route loader |
| Mirroring props/query data into state via `useEffect` | Derive during render |
| Sprinkling `useMemo`/`useCallback`/`memo` | Nothing (compiler) |
| Tailwind v3: `tailwind.config.js`, `@tailwind base`, `tailwindcss-animate`, `shadow-sm`, `outline-none` | `@import "tailwindcss"` + `@theme`, `tw-animate-css`, v4 names |
| Zod 3: `z.string().email()`, `{ message }`, `required_error`, `.strict()`, `.flatten()` | `z.email()`, `{ error }`, `z.strictObject`, `z.treeifyError` |
| TanStack Query v4: positional args, `isLoading`, `cacheTime`, `onSuccess` on `useQuery` | v5 object form, `isPending`, `gcTime` |
| `react({ babel: {...} })` on Vite 8 | `@rolldown/plugin-babel` + `reactCompilerPreset()` |
| Orval ≤ 7 config (`client: 'axios'` by default, CJS config, `mock: true`) | Orval 8 ESM config, fetch, `mock.generators[]` |
| Hand-written API types/fetchers; edits in `generated/` | Regenerate from OpenAPI |
| Only the happy path rendered | Loading/empty/error per §12 |
| CRA/`react-scripts`, Jest + babel-jest, Enzyme | Vite + Vitest + Testing Library |
| `getByTestId` first, `container.querySelector`, manual `act()` around user-event | `getByRole` with name, `userEvent.setup()` |
| Hardcoded strings, string concatenation of translations | `t()` with interpolation |

## 24. Definition of done

- [ ] `npx vitest run --coverage` exits 0; thresholds from `.claude/conventions/react-testing.md` met.
- [ ] `npm run gen:api` produces no diff.
- [ ] Every data view has loading, empty, error states matching the prototype screens.
- [ ] No literal colour/spacing/radius/font size in `src/features` (grep from §16 clean).
- [ ] No physical-direction utilities (grep from §14 clean); `ar` render checked.
- [ ] Every new user-visible string exists in both `en` and `ar`.
- [ ] Every input labelled; icon-only buttons have `aria-label`; axe test passes.
- [ ] No new dependency outside the plan; lockfile updated if one was added.
- [ ] No existing test edited/skipped/deleted unless the plan's `### Tests` table lists it.
